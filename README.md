<h1 align="center">EggSport</h1>

<p align="center">
  All the sportsballs in one place.
</p>

EggSport brings the schedules for your favorite teams together in one simple,
mobile-friendly web app. Browse games by week, sport, or team, then open any
game for its details.

## Features

- Weekly schedules across multiple sports and leagues
- Sport and team filters
- Game detail pages with scores, venues, logos, and status
- Progressive Web App support for mobile installation
- ESPN and MaxPreps schedule data

## Run locally

```bash
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).
